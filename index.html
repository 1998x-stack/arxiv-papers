A daily email from arXiv

The week’s research, distilled.

arxiv-digest pulls the newest machine-learning, AI, neural, and vision papers from arXiv, reads the day’s themes back to you as a word cloud, and sends a clean HTML list straight to your inbox — on a schedule you set.

The pipeline

Fetch. Read. Send.

  1. Fetch

    Query the arXiv API for the latest papers across your chosen categories, sorted by recency.

  2. Distill

    Extract the recurring terms from titles and abstracts and compose them into a word cloud.

  3. Send

    Build an HTML digest — one linked entry per paper — attach the cloud, and deliver it over SMTP.

Run it on demand, or let GitHub Actions send it every morning at 08:00 UTC.

Install

Two commands to your first digest.

# create an environment
python3 -m venv .venv
source .venv/bin/activate

# install and go
pip install -r requirements.txt
pip install -e .
arxiv-digest --dry-run

Usage

Configure it, then forget it.

Everything is read from environment variables — validate a run locally with --dry-run (no credentials, no email), then schedule it and let it run.

Preview without sending

arxiv-digest --dry-run \
  --categories cs.AI --max-results 5

Send a digest

EMAIL_USERNAME=you@gmail.com \
EMAIL_PASSWORD=app-password \
EMAIL_TO=you@gmail.com \
arxiv-digest
Environment variables
VariableDefaultPurpose
EMAIL_USERNAME—account that sends the digest
EMAIL_PASSWORD—app password for that account
EMAIL_TOsenderrecipients, comma-separated
DIGEST_CATEGORIEScs.LG, cs.AI, cs.NE, cs.CVarXiv categories to query
